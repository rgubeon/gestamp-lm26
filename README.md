# LM26 · Gestamp × beon.

Propuesta web para el Leadership Meeting 2026 de Gestamp.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a la raíz de un repositorio (o a `/docs`).
2. En el repositorio: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Elige la rama (`main`) y la carpeta (`/ (root)` o `/docs`) y guarda.
4. En uno o dos minutos la web queda en `https://<usuario>.github.io/<repositorio>/`.

Añade `?final` a la URL para ocultar todos los elementos pendientes.

Es una página estática: no necesita compilación. Las librerías (GSAP, Lenis, Three.js) y las tipografías de Google Fonts se cargan desde CDN.
